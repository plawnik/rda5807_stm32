# Datasheets

Ten katalog zawiera dokumenty producenta i materiały referencyjne zebrane dla
rodziny RDA5807/RDA7088. Implementacja jest przeznaczona dla `RDA5807M`; pliki
dotyczące innych wariantów służą wyłącznie do porównania rejestrów. Funkcje
nieudokumentowane dla użytego układu nie są automatycznie uznawane za
bezpieczne.
