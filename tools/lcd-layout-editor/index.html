Plik projektu

Eksport zawiera pełną strukturę menu, opisy, fonty, warianty grafik, wszystkie klatki oraz bitmapy zarówno jako czytelne wiersze, jak i bajty stron PCD8544.

Format i praca offline

Strona nie wysyła żadnych danych do sieci. Projekt jest automatycznie zapisywany w pamięci lokalnej przeglądarki. Duże GIF-y mogą przekroczyć jej limit — plik JSON pozostaje wtedy podstawową kopią projektu.

Wybierz punkt startowy

Możesz rozpocząć od gotowej struktury radia, wariantu z ikonami albo pustego projektu. Szablon można później wczytać ponownie z górnego paska.
