PCD8544 Layout Editor

Projekt ekranu głównego radia — piksele i opisane obszary funkcjonalne.

84 × 48 px / 1 bit
x: —, y: — Brak wybranego obszaru Włączone piksele: 0 / 4032

Projekt

Projekt jest automatycznie zapamiętywany lokalnie w tej przeglądarce.

Obszary (0)

Wybierz „Nowy obszar” i przeciągnij prostokąt na ekranie. Obszar opisuje przeznaczenie miejsca, ale sam nie zmienia pikseli.

Wybrany obszar

Nie wybrano obszaru.

Plik projektu

Wyślij wyeksportowany plik *.pcd8544-layout.json. Zawiera piksele, 504 bajty bufora PCD8544 oraz nazwy, opisy i geometrię obszarów.

Skróty i obsługa

1 rysowanie, 2 gumka, 3 nowy obszar, 4 wybór obszaru.

Lewy przycisk myszy rysuje wybranym narzędziem. Prawy przycisk zawsze kasuje piksele. W trybie wyboru klawisze strzałek przesuwają zaznaczony obszar.

Ctrl+Z cofa, Ctrl+Y ponawia, Delete usuwa wybrany obszar.
